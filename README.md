# OpenSaaSLabs Website

Official website for OpenSaaSLabs.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Mission

OpenSaaSLabs builds open-source infrastructure, templates, deployment workflows, and operational playbooks for modern SaaS and AI-native teams.
