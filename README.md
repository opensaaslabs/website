# OpenSaaSLabs Website

A Next.js + TypeScript + Tailwind CSS website for OpenSaaSLabs.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- App Router

## Pages

- /
- /tools
- /guides
- /comparisons
- /about

## Mission

Discover, compare, deploy, and govern open-source SaaS and AI tools.
