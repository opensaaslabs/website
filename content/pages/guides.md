## Intro

Choosing a tool is only the first step. Teams also need to understand how to configure it, secure it, monitor it, back it up, and keep it healthy over time. OpenSaaSLabs guides are designed to bridge the gap between evaluation and production adoption.

## Guide Categories

### Installation Guides
Step-by-step setup instructions for getting tools running locally, on a VPS, or in cloud environments.

### Docker Compose Guides
Simple production-minded deployments for small teams, MVPs, demos, and internal tools.

### Kubernetes Guides
Scalable deployment patterns for teams running containerized infrastructure.

### Security Hardening
Authentication, secrets, network access, backups, permissions, and secure defaults.

### Operations Playbooks
Monitoring, logging, upgrades, rollback planning, and maintenance routines.

## Featured Guide Ideas

### Deploy Metabase with PostgreSQL and Docker
Set up Metabase with a persistent PostgreSQL database, environment configuration, reverse proxy, and backup planning.

### Self-host n8n for secure internal automation
Run n8n with credential management, webhooks, queue workers, environment variables, and access control.

### Build an AI application stack with Dify and PostgreSQL
Create a practical AI application foundation with app orchestration, model providers, database persistence, and operational notes.

### Set up monitoring with Prometheus and Grafana
Build a basic monitoring stack for metrics, dashboards, alerts, and service visibility.
